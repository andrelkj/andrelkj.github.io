How this site was built

This page is itself an example of the AI-assisted workflow I use at work. I built it in one session with Claude Code: I set direction, made the content and design calls and reviewed every change. The AI researched, implemented and tested in a real browser.

  1. 01 · audit

    Check the facts first

    Compared the old site with my resume and LinkedIn. It overstated experience, missed a current employer and showed numbers I couldn't back up. New rule: every claim must trace back to the resume, and no number gets invented.

  2. 02 · plan

    Choose for the reader

    Reviewed a terminal-style reference site and kept its look, but chose a normal scrolling layout over an interactive shell, because recruiters skim in under a minute. Removed unused Jekyll and CI files and added a plain static deploy.

  3. 03 · iterate

    Fix what review finds

    My review drove each round: internal project jargon became plain-language results, and a mobile menu that stayed open over the content became an always-visible tab bar with 44px tap targets and a header that hides while you read.

  4. 04 · verify

    Test before shipping

    Every change was checked in a real browser at phone, tablet and desktop sizes before it was committed, in small commits that can each be reviewed on their own. The checks are in the QA report.

Me: direction, content, UX decisions, review and approval. AI: research, code, browser testing, commits. Tools: Claude Code, axe-core, git, GitHub Pages.
